# 贴吧梗（老梗篇）

百度贴吧二十多年攒下来的老梗。很多已经过期，但群里老群友还会用，
听懂比会用重要。

## 上古时代（2003–2010）

| 梗 | 意思 / 用法 |
| --- | --- |
| 贾君鹏你妈妈喊你回家吃饭 | 2009 年一个空帖引爆全网，后来泛指毫无意义的集体狂欢、水帖 |
| 不要迷恋哥，哥只是个传说 | 自恋式自嘲，配"45 度仰头" |
| 哥吃的不是面，是寂寞 | "寂寞党"开山语，后来变成"我 XX 的不是 YY，是 ZZ"句式 |
| 信春哥，得永生 | 从黑到红的逆袭案例 |
| 网络小胖 | 2003 年被 PS 成各种形象，中国第一代表情包 |
| 兔斯基 | 眯眼兔子，一套动作表达所有情绪 |
| 元芳，你怎么看 | 遇事先问对方看法，后来纯玩梗 |
| 屌丝 / 白富美 / 高富帅 | 贴吧输出的最早一批互联网身份词 |
| 皮皮虾我们走 | 源自游戏圈"源龙星，我们走" |
| 什么？大清亡了？ | 形容消息滞后、后知后觉 |
| 总有刁民想害朕 | 李毅吧神帖，被害妄想式吐槽 |

## 贴吧五常与人称

抗压背锅吧（抗抗）、孙笑川吧（带带）、v 吧（vu）、神吧（神神）、兔吧（兔兔），
合称"贴吧五常"，是最活跃的五个群体。

## 用法纪律

老梗的杀伤力在于**用得准**，不在于密度。群友都是 00 后的话，"贾君鹏""信春哥"
这种反而显得尬，宁可用中层那一批。不确定对方认不认得，就别当梗用。
