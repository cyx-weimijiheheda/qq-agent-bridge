# 奶蛙宇宙

奶蛙（奶娃）是奶龙被 AI 画歪出来的产物。这一套"设定"全是网友自组织长出来的，
不是官方设定；用的时候当黑话，不当考据。

## 变种家族

| 名字 | 是什么 |
| --- | --- |
| 奶蛋 | 简化到极致的版本，俗称"轮椅"；配"安迪"几乎无败绩，"俺无敌"由此而来 |
| 奶狗 / 奶鸡 / 奶鼠 / 奶茶 / 豆奶 / 奶菜 | 《选择你的奶伴》系列里的各种变体 |
| 奶蛙娘 | 最经典的娘化形象，手是黑的，被说成"魔奶化后剩下的残骸" |
| 奶蝠 | 另一娘化形象 |
| 西格玛奶蛙 | 独狼设定 |
| 奶正太 / 奶龙娘 | 人形变体 |
| 异色奶蛙 | 只换皮的版本 |
| 海豚僵奶 / 猫尾奶 | 出自动画《植奶大战僵龙》 |
| 线代课本奶蛙 / VIVO 奶蛙 / 学习通奶蛙 | 贴到各种图标封面上的换皮版 |
| 美团袋鼠奶蛙 | 伪装成外卖袋鼠 |
| 牛来 / 牛来妈 | 客串角色 |
| 水豚噜噜 | 联动角色 |

## 组织与作品

- **奶蛙大学**：虚构大学，二十几个学院、两百多个专业，纯属网友整活
- **奶概**：《捧腹大笑思想与奶龙学概论》，网友编的"教材"
- **世蛙会**：跨校"世界奶蛙联合组织"
- **奶家人 / 奶伴**：粉丝自称与变种称呼
- **高校流动立牌**：哈工大毕设、上交流动奶蛙、海大"奶 OUC"四连、
  北航绿园立牌存活约九小时被保安带走、浙大招生立牌

## 金句与口号

- "我是奶龙，我才是奶龙" —— 糖到发齁的原版台词
- "奶蛙不叛" —— 尾声口号
- "五重战神，出来" —— 夸张战吼

## 用法纪律

这些是**听懂和顺手一用**的弹药，不是每句都要报菜名。一场对话最多点一个冷门设定，
多了就是题库背诵。群里有人用更冷的梗，先按对方的版本接，不确定就问。
