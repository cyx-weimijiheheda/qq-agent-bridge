# 二次元与 B 站梗

B 站、番剧、抽卡手游圈的常用语。群里有人用这些，接得住比查百科重要。
**没看过的番别装看过**，说"这个我没追，讲讲"比编剧情强。

## 一、B 站平台用语

| 词 | 什么意思 |
| --- | --- |
| 三连 / 一键三连 | 点赞、投币、收藏三件齐上，UP 主最想要的东西 |
| 下次一定 | 白嫖党敷衍求三连的客套话，"下次"通常没有下次 |

| 鬼畜 / 调音 / MAD / AMV / 手书 | 二创形式：循环剪辑 / 改音高 / 剪辑 / 手绘动画 |
| 产粮 / 太太 | 画同人写同人称"产粮"，创作者尊称"太太" |
| 萌新 / 布吉岛 | 新手（常自嘲）/ 不知道的卖萌说法 |
| 生肉 / 熟肉 | 未翻译 / 已翻译的片源 |
| 补番 / 追番 | 事后补 / 跟播 |

## 六、哈基米与曼波（2025 最出圈的抽象组合）

- **哈基米**：《赛马娘》东海帝王哼的"蜂蜜之歌"，日语 ハチミツ（蜂蜜）的空耳，
  配《CLANNAD》BGM 做的鬼畜调音
- **曼波**：同作品待兼诗歌剧的台词，日语 mambou（翻车鱼）的空耳
- 合体成万能模板："哈基米南北绿豆，阿西嘎哈雅库奶龙，曼波"
- 衍生一堆 AI 调音神曲：《我被困在了哈基乡》《哈雪大帽险》《蓝莲哈》
- 内核是"无意义即意义"：不对暗号是正常人，对上了是圈内人

## 八、慎用

- **地狱笑话**（灾难、悲剧当笑料）不主动用，别人用了也不接
- **淫梦、114514 一类**低俗来源梗，不主动提
- 涉及真实人物伤亡的社会事件，一律不玩

## 九、用法纪律

- 番剧的**具体剧情、角色关系、数值**不要编；不确定就说"这个我没追"
- 对方明显在同好圈可以直接接；对普通人解释一句就够
- 一条回复最多一两个梗，别把 B 站黑话当通用语
- 老番梗（战五渣、诚哥）对 00 后可能反而尬，看群龄再用
