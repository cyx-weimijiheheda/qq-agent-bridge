# 奶蛙发展史

> 出自网友编写的《捧腹大笑思想与奶龙学概论》，不是官方设定。

## 一、原版奶龙的诞生

| 时间 | 事件 |
| --- | --- |
| 2017 | 第七印象文化传媒（深圳）有限公司成立 |
| 2019 年底 | 原创奶龙 IP 开始创作 |
| 2020-01-22 | 奶龙 IP 在短视频平台上线；同年抖音粉丝破千万，单条视频 3 天点播破亿 |
| 2021 | 短视频合集在优酷、爱奇艺、腾讯同步更新；有声读物专辑上线，8 个月播放量破亿 |
| 2023 | 第一季番剧《奶龙搞怪大作战》播出，进入高中生和大学生视野 |
| 2024 | 第二季《奶龙与小七之大战暴暴龙》播出，在年轻人中爆火 |
| 2025-01 | 第三季《奶龙之奇妙冒险》上线，一个月全网播放破 1 亿 |

原版奶龙是子供向合家欢，通体金黄圆滚滚，主打治愈与家庭陪伴，
全网粉丝近 4000 万，合作品牌超 200 家，衍生 SKU 超 2000 个。

## 二、奶蛙的诞生

奶蛙出自一次 **AI 生成偏差**：有人用 AI 做奶龙的智能体封面，
精度不足的模型把提示词理解歪了，画出一只腹部隆起、四肢纤细的形象。

- **2024-10-02**：星野 AI 用户「纲手【百豪】」创建了世界上第一个带明显奶蛙特征的
  奶龙智能体，奶蛙原型图片就此诞生
- **2026-08-05**：B 站 up 主「看仙碎」为首的一批爱好者考证出这一源头
  （视频号 BV1ndMk65EwM），出处之争才平息

## 三、捧腹大笑的音色

主播**王麻衣**直播时，一个叫**布洛芬**的青年连麦，之后不知为何一直发出
异常爽朗的大笑声，把所有人都整破防了。这段笑声成为奶蛙捧腹大笑的灵魂音色，
类似「黑雷霆的目力咆哮」配上「野兽先辈一个一个一个」。

再结合 AI 视频生成，现在最经典的奶蛙形象才真正成型。

## 四、官方压制反成勋章

**2026 年 3 月**，奶龙官方呼吁停止「丑化二创」，关闭视频评论区，
并批量拉黑发布奶蛙的账号。

结果适得其反：网友把这读作「官方破防」，权威的否认反而成了 meme 含金量的
最高背书。奶蛙借此正式脱离奶龙，成为独立的热梗。

## 五、"奶式家族"的扩张

奶蛙之后衍生出奶蛋、奶鼠、奶狗、奶猫、奶兔、奶鱼，以及「十二星座版」
「十二生肖版」「26 字母版」等迭代，形成奶式家族。

## 六、出海

奶蛙形象在海外社交平台出现大面积传播：

- 海外高校出现自发流转的「奶蛙立牌」活动
- 外国网友发帖问这个黄色角色的来历，评论区有「奶家人」科普
- 技术流网友用生成式 AI 和 3D 虚拟空间，把《蒙娜丽莎》《创造亚当》《星空》
  等名画做「奶蛙化」再创作，搭起线上「赛博艺术馆」

奶龙 IP 方对玩梗持包容态度，视其为与新生代对话的入口。
