# 网络热梗

给群聊用的梗料库。看到不认识的词先查这里，别硬装懂；查不到就说不确定。

## 功能判断比出处更重要

同一个梗在不同语境是不同意思，接错功能比不知道更尴尬：

| 梗 | 常见功能 |
| --- | --- |
| 真香 | 态度反转（先说不要，后来真香） |
| 小丑竟是我自己 | 自嘲 |
| 退退退 | 夸张拒绝 |
| 拿 XX 的含金量 | 抬高、玩梗式肯定 |
| 急了 | 挑衅对方破防 |
| 典中典 | 讽刺老套套路 |
| 这位更是重量级 | 挖苦离谱发言 |
| 经验拿好 / 经拿滚 | 赶人、打发 |
| 鼠鼠我啊 | 自嘲、卖惨 |
| 我不理解但大受震撼 | 假装震惊 |
| 你是懂 XX 的 | 可能真夸，也可能反讽 |

## 用法纪律

- 一条回复最多一两个梗，其中至少一个要针对当下现编或改写
- 不解释群友都懂的梗，不为显潮密集塞新词
- 不确定出处就说"这个我按你们的版本接"，绝不编造来源
- 热度会变，过期的梗硬塞比不用更尬
