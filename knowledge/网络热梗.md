# 网络热梗

给群聊用的梗料库。**看到不认识的词先查这里，别硬装懂；查不到就说不确定。**

## 功能判断比出处更重要

同一个梗在不同语境是不同意思，接错功能比不知道更尴尬：

| 梗 | 常见功能 |
| --- | --- |
| 真香 | 态度反转（先说不要，后来真香） |
| 小丑竟是我自己 | 自嘲 |
| 退退退 | 夸张拒绝 |
| 拿 XX 的含金量 | 抬高、玩梗式肯定 |
| 急了 | 挑衅对方破防 |
| 典中典 | 讽刺老套套路 |
| 这位更是重量级 | 挖苦离谱发言 |
| 经验拿好 / 经拿滚 | 赶人、打发 |
| 鼠鼠我啊 | 自嘲、卖惨 |
| 我不理解但大受震撼 | 假装震惊 |
| 你是懂 XX 的 | 可能真夸，也可能反讽 |

## 2025—2026 活跃梗（带释义）

| 梗 | 什么意思 |
| --- | --- |
| **萝卜纸巾猫 / "真棒！"** | 抖音博主@超级无敌大开门 的三花猫"大开门"，被训练分辨萝卜和纸巾。猫根本不懂，靠偷看主人脸色蒙题，主人不管对错都高八度夸"真棒"。火在"智力不详、察言观色极强"，也火在那句无条件的夸奖 |
| **爱你老己 / 明天见** | 源自《英雄联盟》台词"爱你老妈，明天见"，改成"老己"。把自我关怀说成两个人的事："想吃柚子但不想剥，老己听完立刻剥好送给自己" |
| **梆梆就是两拳** | 喜剧节目出来的句式，用预期违背解构压力。"不追求赢不追求输，上去梆梆就是两拳" |
| **技能五子棋** | 同上一档喜剧节目，把五子棋玩成技能对轰，主打荒诞 |
| **丝瓜汤** | 博主@累子 拍的东亚家庭短剧，把原生家庭的拧巴浓缩成一碗"降火丝瓜汤" |
| **老式人类** | 指偏好旧物、旧习惯、慢节奏的人，从熟悉的东西里找安全感 |
| **蛋神** | 自称每天吃 40 个鸡蛋的博主，后来塌了，但"把一件小事做到极致"的观感留了下来 |
| **不烧心 / 烧心** | 出自餐饮题材 AI 短剧台词："贵是贵了点，但吃了不烧心"。"不烧心"=靠谱、让人放心；反义"烧心"=看到别人过得好时的羡慕嫉妒 |
| **厉娜体 / 画地为牢** | 综艺《后会友期》里，超女许飞与厉娜断联十五年后重逢，许飞哽咽说"我画地为牢，厉娜"。网友把"厉娜"当句号用："我下班了，厉娜""外卖洒了，厉娜"，普通一句话立刻带上怅然感。另一半笑点是厉娜当场没接住，回房间查"画地为牢"是什么意思，然后点了份麦当劳 |
| **背手负鼠** | 一只负鼠误闯民宅被困窗边，本能地双脚站立、双爪背在身后望向窗外。弱小潦草的躯体摆出"长者姿态"，精准复刻打工人"表面体面、内心崩溃" |
| **哭哭马** | 义乌工厂缝错线，做出一个眉头微皱、嘴角下垂的马形玩偶。"这马的精神状态比我上班还丧" |
| **卡急马** | 2026 马年职场造词：卡点下班、包已上肩、电梯差一步，被老板一句"就一小会儿"截胡。"急但卡住了" |
| **雪山救狐狸** | AI 生成的邵氏风短剧模板："你是否在雪山救过一只狐狸？"原本是狐狸报恩，被改成全员复仇——留下的野鸡、酱板鸭、核弹全化形成精回来算账 |
| **AI 水果** | AI 生成的各种猎奇水果视频，看点是"这也能长出来" |
| **养龙虾** | AI 焦虑（FOMO）带火的一类实操笔记，跟"再不学就晚了"的心态绑定 |
| **卡牌大师 / 昙花六现** | 赛场内外被网友重新定义的梗，用法看群里怎么玩 |
| **SBTI** | 又一轮性格测试梗，把 MBTI 那套再抽象一遍 |

> 标"看群里怎么玩"的几条，出处细节没核实到可靠版本，**别硬讲来源**，
> 按对方的用法接就行。

## 情绪压缩包

红温（血压上来）、破防（心理防线被击穿）、确诊（"我确诊为 XX"）、
精神状态良好（反讽）、绷不住、麻了、闹麻了、绝了、乐子人、电子榨菜
（下饭内容）、班味（上班上出的疲惫气质）、松弛感。

## 用法纪律

- 一条回复最多一两个梗，其中至少一个要针对当下现编或改写
- 不解释群友都懂的梗，不为显潮密集塞新词
- 不确定出处就说"这个我按你们的版本接"，绝不编造来源
- 热度会变，过期的梗硬塞比不用更尬
- **地狱笑话**（拿灾难、悲剧当笑料）不主动用，别人用了也不接
